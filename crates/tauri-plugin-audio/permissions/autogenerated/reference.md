## Default Permission

Default permissions for the audio plugin

#### This default permission set includes the following:

- `allow-list-render-devices`
- `allow-list-capture-devices`
- `allow-get-engine-status`
- `allow-start-engine`
- `allow-stop-engine`
- `allow-set-channel-volume`
- `allow-set-channel-mute`
- `allow-set-crossfade`
- `allow-set-master-volume`
- `allow-set-master-mute`
- `allow-search-headphones`
- `allow-apply-autoeq-profile`
- `allow-update-eq-filter`
